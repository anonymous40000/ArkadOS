### как это работает

стейдж1 грузит стейдж2 с диска, стейдж2 в реал-моде читает kernel.bin с диска
во временный буфер, включает protected mode, копирует ядро на 1 МиБ, строит
identity-paging первых 4 МиБ, включает long mode и прыгает в `_start` ядра.

сейчас всё завязано на одну дорожку диска: стейдж1(1 сектор) + стейдж2(6) +
ядро(10) = 17 из 18 доступных секторов на дорожке. если стейдж2 или ядро
вырастут — либо увеличивай `STAGE2_SECTORS`/`KERNEL_SECTORS` в Makefile (пока
укладываешься в 18), либо добавляй поддержку чтения с нескольких дорожек в
загрузчик (CHS с переносом через головы/цилиндры).
